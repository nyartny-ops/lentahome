# Дом Лента · лендинг с блогерами (макет)

Статичный сайт без сборки и бэкенда. Просто откройте `index.html` или залейте папку на любой хостинг
(Nginx, GitHub Pages, Netlify, Vercel, Tilda Zero не нужна). Все шрифты и иконки лежат локально.

## Что работает
- История автора по этапам (статья), липкая навигация по шагам с прогрессом
- Подборка товаров по этапам: вкладки, добавление в список, «добавить этап», «добавить весь набор»
- «Мой список»: количество, сумма, копирование списка, кнопка в каталог; на мобиле шторка снизу
- Опыт авторов: переключение по задачам (ремонт, ванная, декор, сад)
- Плитки других задач, блок UGC с хэштегом
- Светлая и тёмная тема (по системе), адаптив, reduced motion

Список хранится только в браузере (localStorage), ничего никуда не отправляется.

## Где править
- Тексты истории и блоков: `index.html`
- Товары, цены, авторы, ссылка на каталог: `assets/js/data.js`
- Стили и цвета: `assets/css/style.css` (переменные в начале файла)

Имена авторов, охваты и цены в макете условные.
